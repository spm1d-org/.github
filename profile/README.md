# spm1d.org

One-dimensional Statistical Parametric Mapping and related packages.



Documentation: [spm1d.org](https://spm1d.org/)



| Package | Description | Repository |
|---|---|---|
| [spm1d v0.4 (Python)](https://spm1d.org/spm1d-v0.4/) | One-dimensional Statistical Parametric Mapping | [spm1d-v0.4](https://github.com/spm1d-org/spm1d-v0.4) |
| [spm1d v0.4 (MATLAB)](https://spm1d.org/spm1d-v0.4/install/InstallationMatlab.html) | One-dimensional Statistical Parametric Mapping | [spm1d-matlab-v0.4](https://github.com/spm1d-org/spm1d-matlab-v0.4) |
| [rft1d](https://spm1d.org/rft1d/) | Random Field Theory expectations for upcrossings in 1D continua | [rft1d](https://github.com/spm1d-org/rft1d) |
| [power1d](https://spm1d.org/power1d/) | Statistical power for 1D continua | [power1d](https://github.com/spm1d-org/power1d) |
